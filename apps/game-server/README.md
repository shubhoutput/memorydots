# memorydots game server

The Colyseus server foundation for Remote and Random play. It currently has no
game rooms or gameplay logic; those will be implemented from
[`../../GAME_SPEC.md`](../../GAME_SPEC.md), with the server authoritative for
both modes.

## Development

Install dependencies with `npm install`, then run:

```sh
npm run dev
```

The Colyseus playground and monitor are available in development mode.
